Free interactive SVG animations

Line animations that look back at your visitors.

animatedSVG is a free library of hand-built 3D line figures that react to the pointer. Each one is a single HTML file with no dependencies. Copy it, embed it, or download it, and it works on any website.

What it is

Small, alive, and easy to drop in.

Most animation kits ship a runtime, a build step and a bundle. These are plain files you can read, paste and change.

01

Reacts to the pointer

Figures wake up, turn and follow the cursor on springs, then settle back to rest.

02

One file each

Markup, styles, engine and figure in a single HTML file. No npm, no bundler, no CDN.

03

Light and dark

Follows the visitor's colour scheme automatically, or force one with a single attribute.

04

Crisp at any size

Drawn as SVG paths, so lines stay sharp on every screen and zoom level.

How it works

3D shapes, drawn as lines.

Each figure is built from simple 3D solids: ellipsoids, tubes and boxes. A small engine projects them through a camera and outlines each one as an SVG path. Pointer movement sets targets for springs, and a frame loop redraws the paths until the springs settle, so nothing runs while the figure is at rest.

  1. Choose a figure

    Try them live in the gallery and pick the one that fits your page.

  2. Copy the embed or the code

    Copy embed gives an <iframe> that loads the figure from this site. Copy code gives the whole file to host yourself.

  3. Paste it into your site

    Works in plain HTML, WordPress, Webflow, React or anything else that accepts HTML.

  4. Set the theme (optional)

    Add data-theme="light" or "dark" to the figure's <html> tag to lock its colours.

Tech stack

Built on the web platform.

SVG

Every line is an SVG path, so it scales without blur.

Vanilla JavaScript

No framework. Springs and a requestAnimationFrame loop that sleeps at rest.

CSS custom properties

Theme colours and light/dark modes with prefers-color-scheme.

Hairline engine

Open-source 3D-to-line engine by Lucas Marques, MIT licensed.

Vercel

Static hosting on a global edge network.
