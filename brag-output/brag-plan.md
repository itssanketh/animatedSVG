# brag plan — animatedSVG

**What it is:** 160 free line-art figures that react to your pointer, one dependency-free HTML file each.
**For:** anyone building a website who wants a small living illustration without a library.
**Sets it apart:** they *answer* you — a cat wakes and watches, Arch builds itself, a heap sifts up — and each is a single file.
**Most impressive claim:** 160 figures, 0 dependencies.
**Visual hook:** a sleeping line cat wakes up and follows the cursor.
**Tone:** `polished` leaning `default` — matches the site's Apple-style restraint. White ground, #1d1d1f ink, Inter semibold with tight tracking, #0071e3 accent used once.
**Share caption:** Line art that moves when you do — 160 free SVG figures, one HTML file each.

## Sound
Soft, warm minimal track in A major, ~100 BPM: felt-piano plucks + sub pad, synthesized in Python. Effects in-key: a gentle chime when the cat wakes, soft ticks on cursor touches (low in the mix), a resolving chord on the outro.
